# data-engineering — 数据工程与数据治理（Today I Learned 第 50 站）

大白话讲透「怎么把散落各处的数据,变成可管理、可信任、可复用的资产」（科普通识，非平台选型、合规审计与投资测算依据）。克隆 `iot-sensing`(IOT) 共享引擎（IOT→DEG 命名空间替换），内容完全重写。「今日得到」合集第 50 站。

## 给谁看 / 讲什么 / 不讲什么 / 调性
- **给谁看**：刚入行或要转数据方向的人、做数据分析/BI/数仓的工程角色，以及要牵头或参与数据治理、却不确定「治理到底治什么」的业务与技术管理者。
- **讲什么**：一份数据从进厂到出厂的整条链——建模 → 存储 → 采集 → 管道 → 质量 → 元数据 → 血缘 → 标准 → 安全 → 治理 → 服务 → 面向 AI 的数据供给。
- **不讲什么**：不重复数据库内核与 SQL 语法细节（`data-literacy`）、不重复机器学习算法（`machine-learning`）、不重复 AI 应用的工程落地（`ai-engineering`）、不重复云平台选型（`cloud-native`）。本站讲的是**数据工程与数据治理的判断与逻辑**。
- **调性**：大白话、口语化、给具体场景例子（数仓建模、指标口径打架、主数据重复、血缘影响面、数据分级），每课都给「能带走的一个判断」。

## 与兄弟站的边界

| `database-*` / 数据库类 | 数据库内核与调优 | 不讲内核，只讲建模与使用侧 |

## 技术与合规约束（必须有）
1. **常驻声明**：`index.html` 的 `.notice-bar`、首页 `.disclaimer`、课时页模块提示三处都要有，基线 **2026-10**。
2. **不构成依据**：一律写明「通识科普，不构成平台选型、合规审计、投资测算或法律依据」。
3. **口径随文件变**：涉及数据标准、行业规范、监管要求之处，标注「以现行国家标准(GB)、行业标准与本单位制度为准」。
4. **个人信息与敏感数据**：强调最小必要、分类分级、脱敏与安全可控。
5. **成本与单价**：工具中的单价、比率为示例概数，标注「实际须以真实数据探查与平台实测核算」。

## 7 件互动工具（`views-tools.js`）
| 函数 | 结果容器 | 算法要点 |
|---|---|---|
| `calcDataVolume` | `dv-result` | 单行字节 = 字段数×平均字节；原始日增 = 行数×单行字节；压缩后日增 = 原始÷压缩比；年增量、保留期总存储、平均每秒行数 |
| `calcQualityScore` | `qs-result` | 六维度加权总分（完整性 .20/准确性 .20/一致性 .15/及时性 .15/唯一性 .15/有效性 .15）→ 等级（优/良/中/差）并指出短板维度 |
| `calcLineageImpact` | `li-result` | 下游表 = 上游表×每表下游×(1+每层衰减累加)；受影响任务 = 下游表×每表任务；按规模定影响等级（低/中/高/极高） |
| `calcDataClass` | `dcl-result` | 按「含个人信息/含财务敏感/受法规强约束/使用范围」加权定级（公开/内部/秘密/机密），并列出对应管控措施清单 |
| `calcMdmMatch` | `mm-result` | 重复记录 = 总量×重复率；自动识别 = 重复×匹配准确率；待复核 = 重复−识别；省下成本 = 自动识别×单条核对成本 |
| `calcMetricConsistency` | `mcs-result` | 差异率 = \|A−B\| ÷ max(A,B)；与阈值比较判定是否超容忍线，并给口径统一建议 |
| `calcDataCost` | `dco-result` | 月总成本 = 存储(TB×单价)+计算+人力；单 TB 成本 = 总成本÷TB；产出/投入比 = 月价值÷月成本 |

## 内容源写法陷阱（`tools/_src/*.js`）
- 本站引擎（IOT 系）的 `_src/*.js` 是「**裸赋值 + helpers**」写法：`L.<moduleid> = [ ... ];`，由 `build.js` 用 `eval()` 加载，**不要写 `module.exports`**。
- helpers 只有 `g/ex/pit/fml/qc`，**没有 `qf`**；只能在引号外用 `+` 拼接。
- ⚠️ `L.eval = [` 这类模块 id 若恰好叫 `eval`，会与 `eval()` 冲突——本站无此问题，但命名模块时留意保留字。
- 课时元组**顶格从 `[` 开始**（不要缩进），9 元素：`[slug, 标题, 分钟, [关键词], concept, core, pitfalls, quiz数组, links]`。
- concept 必须以「一句话:」开头；逗号/冒号/问号/分号用**半角**，句号用**全角 `。`**；引号「」，破折号 `——`；**禁止 emoji**。
- `tools/_src` 文件用 `NN-<moduleid>.js` 编号；插入模块后必须 `mv` 重排编号。
- ⚠️ **`cp -R` 克隆时若目标目录已存在会套一层**；克隆后必须 `ls` 确认没有多余嵌套。
- ⚠️ BSD/macOS 的 `sed` 无 `\b`（用 `perl -pi -e`）；Bash `grep` 查中文行易假阴性（用 Grep 工具/ripgrep）。
