# ai-product-design — AI 产品与交互设计（Today I Learned 第 49 站）

大白话讲透「怎么把一个 AI 能力做成用户愿意用、用得顺、信得过的产品」（科普通识，非产品决策与投资测算依据）。克隆 `iot-sensing`(IOT) 共享引擎（IOT→APD 命名空间替换），内容完全重写。「今日得到」合集第 49 站。

## 给谁看 / 讲什么 / 不讲什么 / 调性
- **给谁看**：想入门 AI 产品的人、做产品/设计/运营的角色，以及要把 AI 用到业务里但不确定「这活该不该做、做出来长什么样」的人。
- **讲什么**：从一个念头到被用起来的整条链——用户研究 → 任务设计 → 交互范式 → 提示词与内容 → 信任建设 → 原型验证 → 指标度量 → 伦理与协作。
- **不讲什么**：不重复模型原理（`artificial-intelligence` / `machine-learning`）、不重复后端与上线工程（`ai-engineering`）、不重复智能体技术实现（`ai-agents`）、不重复数据分析方法（`data-literacy`）。本站讲的是**产品判断与交互设计**。
- **调性**：大白话、口语化、给具体场景例子（AI 助手、智能客服、内容生成、企业场景），每课都给「能带走的一个判断」。

## 技术与合规约束（必须有）
1. **常驻声明**：`index.html` 的 `.notice-bar`、首页 `.disclaimer`、课时页模块提示三处都要有，基线 **2026-10**。
2. **不构成依据**：一律写明「通识科普，不构成产品决策、投资测算、无障碍认证或合规依据」。
3. **口径随文档变**：涉及模型能力、平台功能、计费口径之处，标注「以所用平台官方文档为准」。
4. **无障碍**：涉及 WCAG 之处标注「以现行 WCAG 标准为准」。
5. **用户数据**：强调最小必要、知情同意与隐私设计。

## 技术架构
- 纯静态、零依赖、离线可用；共享引擎（`window.APD`）。
- 进度：`localStorage['apd.progress.v1']`；同步路径 `progress/ai-product-design.json`；token 仅存本机 `<ns>.sync.v1`。
- 双主题：`document.documentElement.dataset.theme`；字号 `dataset.fs`。

## 7 件互动工具（`views-tools.js`）
| 函数 | 结果容器 | 算法要点 |
|---|---|---|
| `calcTaskFit` | `tf-result` | 适配总分 = (结构化×0.35 + 容错×0.35 + 数据×0.30)×10；减「人在回路必要性×1.5」得判定分 |
| `calcFunnel` | `fn-result` | 各环转化率 + 总体转化；找最低环，算该环 +10 个百分点后总体提升 |
| `calcDialogTurn` | `dt-result` | 任务完成率、未完成数、澄清率、办成一件平均轮次 = 总轮次 ÷ 完成数 |
| `calcCollabLoad` | `cl-result` | 审核工时 + 返工工时 = 人工总负荷；对全人工基线的释放比例 |
| `calcContrast` | `ct-result` | sRGB 线性化 → 相对亮度 → 对比度 (L1+0.05)/(L2+0.05)；AA/AAA 判定（大字 3/4.5，正文 4.5/7） |
| `calcUsabilityN` | `un-result` | n = ln(1−目标) ÷ ln(1−单用户概率)，给出 80/85/90% 三档 |
| `calcPricing` | `pr-result` | 单客户边际贡献 = 席位数×单价 − 单客户成本；盈亏平衡客户数 = 固定成本 ÷ 边际贡献 |

## 内容源写法陷阱（`tools/_src/*.js`）
- 本站引擎（IOT 系）的 `_src/*.js` 是「**裸赋值 + helpers**」写法：`L.<moduleid> = [ ... ];`，由 `build.js` 用 `eval()` 加载，**不要写 `module.exports`**。
- helpers 只有 `g/ex/pit/fml/qc`，**没有 `qf`**；只能在引号外用 `+` 拼接。
- ⚠️ `L.eval = [` 这类模块 id 若恰好叫 `eval`，会与 `eval()` 冲突——本站无此问题，但命名模块时留意保留字。
- 课时元组**顶格从 `[` 开始**（不要缩进），9 元素：`[slug, 标题, 分钟, [关键词], concept, core, pitfalls, quiz数组, links]`。
- concept 必须以「一句话:」开头；逗号/冒号/问号/分号用**半角**，句号用**全角 `。`**；引号「」，破折号 `——`；**禁止 emoji**。
- `tools/_src` 文件用 `NN-<moduleid>.js` 编号；插入模块后必须 `mv` 重排编号。
- ⚠️ **`cp -R` 克隆时若目标目录已存在会套一层**；克隆后必须 `ls` 确认没有多余嵌套。
