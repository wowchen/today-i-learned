# 机器学习入门 (ML)

大白话讲透机器学习（科普通识，非应试、零代码）。克隆 `data-literacy` 共享引擎（DAT→ML 命名空间替换），内容完全重写。

## 站点定位

- **给谁看**：想搞懂机器学习到底怎么回事、但不需要自己调模型的人——产品/运营/业务分析岗、被"AI 项目"卷进来的项目经理、刚转方向的技术人。
- **讲什么**：机器学习是什么与不适用边界、建模全流程、回归/分类/无监督的代表算法、评估与调优、特征与数据准备、神经网络与大模型、推荐系统与时间序列、实战避坑。
- **不讲什么**：数学推导、代码实现、具体工具 API、可照搬的调参方案。重"为什么"和"什么时候不该用"，轻"怎么按"。
- **调性**：大白话、一课一个点、有判断。每个概念先给一句人话，再展开。案例数字均为教学演示。
- **与兄弟站的边界**：#14 AIX 讲 AI 大图景、#24 AIP 讲 AI+电力、#32 AGT 讲 Agent 工程、#34 DAT 在 CLAUDE.md 里明确写了"不讲机器学习"——本站补的正是 DAT 留出的那块白。

## 目录结构

- `tools/build.js` — 单一数据源：MODULES 模块表 + TERMS 术语表，加载 `tools/_src/*.js` 课程内容
- `tools/_src/` — 课程内容（一模块一文件，共 12 个）：`01-intro.js` … `12-practice.js`
- `content/` — 构建产物（自动生成，勿手改）
- `assets/js/views-home.js` — 首页（散点云 + 拟合曲线 SVG hero，翠玉绿主题）
- `assets/js/views-tools.js` — 4 件互动工具 + 模块/术语/搜索/设置视图

## 课程格式（五段式）

每课数组：`['slug','标题',minutes,['关键词'], concept, core, pitfalls, quiz[], links]`

- `concept` 一句话人话版；`core` 主体（配 `ex()` 例子）；`pitfalls` 用 `pit()`；`quiz` 用 `qc()`；`links` 下一课链接
- 术语引用：`g('term-id','术语')` 生成可点击术语，id 必须在 TERMS 中定义
- 构建：`node tools/build.js`，自动校验术语引用、内部链接、emoji

⚠️ 写 `_src` 时两条硬规矩：① 不要在半角单引号字符串里再用半角单引号（会被截断，用「」替代）；② `g()/ex()/pit()` 必须写在字符串**外面**用 `+` 拼接，写进字符串内部会原样输出到页面且不会被校验发现。

## 互动工具（views-tools.js）

1. **线性回归拟合器** — 拖滑块调斜率/截距，实时看残差与误差平方和（SSE），可一键跳到最小二乘最优解
2. **阈值与混淆矩阵** — 滑阈值看 TP/FP/FN/TN、精确率/召回率/F1，并与"全判否"基线对比
3. **K 均值聚类演示器** — 迭代一步 / 自动跑到收敛，看中心移动与分组变化
4. **过拟合演示器** — 多项式次数滑块，看训练误差与验证误差的分叉（高次需先归一化 x，否则数值病态）
