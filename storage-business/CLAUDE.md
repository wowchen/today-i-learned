# storage-business — 储能商业模式（Today I Learned 第 53 站）

大白话讲透「储能到底靠什么赚钱、收益怎么算、容量怎么配、投资划不划算」（科普通识，非投资测算、项目决策、报价或结算依据）。克隆 `iot-sensing`(IOT) 共享引擎（IOT→ESB 命名空间替换），内容完全重写。「今日得到」合集第 53 站。

## 给谁看 / 讲什么 / 不讲什么 / 调性
- **给谁看**：储能投资商与开发商的测算岗、工商业用户的能源管理岗、综合能源服务与 EMC 从业者、要评估储能项目的融资与商务人员，以及想读懂「峰谷套利」「共享储能」「LCOS」「容量租赁」新闻的普通人。
- **讲什么**：储能的**商业与算账链**——为什么需要储能 → 价值从哪来 → 技术路线怎么选 → 收益怎么测算 → 峰谷套利与需量管理怎么算 → 辅助服务挣多少 → 现货与容量收益怎么看 → 共享储能怎么租 → 工商业 EMC 怎么分 → 电网侧与电源侧怎么定位 → 和虚拟电厂怎么协同 → 市场化机制怎么变 → 投资怎么测算 → 真实案例怎么复盘。
- **不讲什么**：不重复储能设备本体、电池化学与系统集成（`new-power-storage` 新型电力系统与储能）、不重复电力市场的交易品种与出清算法（`power-market`）、不重复现货的报价与结算操作细节（`power-spot-market` 本站兄弟 SPOT）、不重复能源政策与碳资产规则（`energy-carbon`）。本站讲的是**把储能当一门生意来算账**。
- **调性**：大白话、口语化、给具体的账（一天套几次、度电成本几毛、几份收入叠加、几年回本），每课都给「能带走的一个判断」。

## 技术与合规约束（必须有）
1. **常驻声明**：`index.html` 的 `.notice-bar`、首页 `.disclaimer`、课时页模块提示三处都要有，基线 **2026-10**。
2. **不构成依据**：`.notice-bar` 写明「本站不构成投资测算、项目决策、报价、财务或法律依据」；首页 `.disclaimer` 写明「本站为通识科普，不构成投资测算、项目决策、报价、财务或结算依据」；课时页模块提示写明「本站不构成投资测算、项目决策或结算依据」。
3. **口径随文件变**：涉及电价机制、辅助服务补偿、容量租赁、需求响应与补贴政策之处，一律标注「以现行有效的价格政策、市场规则、主管部门文件与结算办法为准」。
4. **时效性强**：峰谷价差、辅助服务单价、容量租赁价格与补贴标准变化快，正文一律写「示例概数」并提醒读者核对最新文件。
5. **不引战、不预测**：不对储能投资回报、政策松紧作预测或倾向性评价；只讲机制与算法怎么运作。

## 7 件互动工具（`views-tools.js`）
| 函数 | 结果容器 | 算法要点 |
|---|---|---|
| `calcStorageRevenue` | `sr-result` | 单次放电电量 = 容量 × 1000 × 循环效率；日套利 = 放电电量 × 峰谷价差；年套利按运行天数折万元；合计 = 年套利 + 容量租赁 + 辅助服务；度电收益 = 年收益合计 ÷ 年放电量 |
| `calcLcos` | `lc-result` | 资金回收系数 CRF = r(1+r)^n ÷ ((1+r)^n − 1)；投资年化 = 单位投资 × CRF；年总成本 = 投资年化 + 运维；年放电量 = 放电深度 × 循环效率 × 年循环次数；LCOS = 年总成本 ÷ 年放电量；与参考峰谷价差比判有无套利空间 |
| `calcStorageSizing` | `sz-result` | 所需容量 = 削峰功率 × 持续时长 ÷（放电深度 × 循环效率）；需量年节省 = 削峰功率 × 需量电价 × 12；年套利 = 日放电量 × 价差 × 天数；投资 = 容量 × 单位造价；静态回收期 = 投资 ÷ 合计年收益 |
| `calcAncillaryIncome` | `ai-result` | 容量补偿 = 可调节容量 × 1000 × 容量补偿单价；里程补偿 = 里程 × 里程单价 × 考核系数；考核折减 = 里程 × 里程单价 ×（1 − 考核系数）；单位容量年收益 = 合计 ÷ 可调节容量 |
| `calcSharingAllocation` | `sa-result` | 出租容量 = 用户数 × 单户容量；出租率 = 出租容量 ÷ 电站容量（超 100% 报超卖告警）；年租赁收入 = 出租容量 × 1000 × 租赁单价；净收益 = 租赁收入 − 运维；回收期 = 投资 ÷ 年净收益 |
| `calcEmcSplit` | `es-result` | 业主年收益 = 年总收益 × 业主分成比例；投资方年收益 = 年总收益 − 业主分成 − 运维；投资方回收期 = 项目投资 ÷ 投资方年收益；再算合同期内双方累计与投资方净收益 |
| `calcInvestmentReturn` | `ir-result` | 静态回收期 = 投资 ÷ 年净收益；NPV = Σ 年净收益÷(1+r)^t + 残值÷(1+r)^n − 投资；IRR 用二分法（区间 [−0.9, 2]，迭代 200 次）解 NPV = 0，与资金成本直接比 |

## 内容源写法陷阱（`tools/_src/*.js`）
- 本站引擎（IOT 系）的 `_src/*.js` 是「**裸赋值 + helpers**」写法：`L.<moduleid> = [ ... ];`（如 `L.arbitrage`），由 `build.js` 用 `eval()` 加载，**不要写 `module.exports`**。
- helpers 只有 `g/ex/pit/fml/qc`，**没有 `qf`**；只能在引号外用 `+` 拼接。
- ⚠️ `L.eval = [` 这类模块 id 若恰好叫 `eval`，会与 `eval()` 冲突——本站无此问题，但命名模块时留意保留字。
- 课时元组**顶格从 `[` 开始**（不要缩进），9 元素：`[slug, 标题, 分钟, [关键词], concept, core, pitfalls, quiz数组, links]`。
- ⚠️ **`core` 必须是数组**（每项一个「小标题 + 正文」块）；写成字符串会导致 `build.js` 抛 `(les[7] || []).forEach is not a function`。
- concept 必须以「一句话:」开头；逗号/冒号/问号/分号用**半角**，句号用**全角 `。`**；引号「」，破折号 `——`；**禁止 emoji**。
- `tools/_src` 文件用 `NN-<moduleid>.js` 编号；插入模块后必须 `mv` 重排编号。
- ⚠️ **`cp -R` 克隆时若目标目录已存在会套一层**；克隆后必须 `ls` 确认没有多余嵌套。
- ⚠️ BSD/macOS 的 `sed` 无 `\b`（用 `perl -pi -e`）；Bash `grep` 查中文行易假阴性（用 Grep 工具/ripgrep）。
- ⚠️ **zsh 不对未加引号的 `$VAR` 做词分割**：`perl -pi -e '...' $FILES` 会把整串当一个文件名（报 `File name too long`），须改用 `find ... -print0 | xargs -0 perl -pi -e '...'`。
