# AI 智能体 · Agent 与工作流 (AGT)

大白话讲透 AI 智能体与工作流（科普通识，非应试）。克隆 `telecom-fundamentals` 共享引擎（TCM→AGT 命名空间替换），内容完全重写。

## 站点定位

- **读者**：用 AI 干活的人（写报告/做研究/搭自动化）、想搞懂 Agent 的人、AI+电力场景的开发者
- **视角**：工程直觉优先——每个概念都回答"它解决什么问题、坏起来什么样、怎么用才靠谱"
- **红线**：不神化不贩卖焦虑；框架与产品名迭代快，讲方法论不讲站队；token 用量为教学估算

## 互动工具（5 件，views-tools.js）

1. **智能体循环模拟器**：真实任务（会议纪要）的 12 步轨迹回放，看循环怎么转、计划怎么改
2. **提示词体检**：按角色/任务/背景/约束/输出格式五要素启发式打分
3. **上下文预算计算器**：窗口/系统提示/知识库/历史/输出预留的分配与超限预警
4. **流水线设计器**：5 条预设流水线的工序、token 账单与适用场景对照
5. **失败模式自诊器**：6 类症状 → 失败模式定位 + 根因清单 + 药方 + 相关课程链接

## 技术要点

- 主题：浅色冷白+紫罗兰（#6d28d9）/ 深色深紫夜+亮紫（#b794f6）
- 首页 hero：智能体循环 SVG（感知/思考/行动三节点 + 中心芯片 + core-flow 脉冲流动）
- `tools/build.js` 单一数据源：MODULES/TERMS + `_src/*.js`（`L.<mod>` 数组，课程五段式：one/core+ex/pit/quiz/next），校验术语引用与内部链接后生成 `content/` 并注入 index.html `<!--LESSONS-->`
- 数据格式：`AGT.registerLesson({id:'mod/slug', concept, core, pitfalls, quiz, links, ...})`
- GitHub 同步与其他站一致：localStorage `agt.progress.v1`，路径默认 `progress/agt.json`
- 改内容后必跑 `node tools/build.js`；改引擎/CSS 后 bump index.html 资源版本参数
